How to use this page

Pick a card count (6 → 1), a quote mix and a viewport. Both sections below re-render live with the exact CSS proposed in Docs/google-reviews-sections-build-spec.md. Desktop rules apply above 900px of frame width (this page uses container queries so the mobile frame really switches; production uses @media (min-width:901px) at the same breakpoint). All reviewer text below is invented sample copy in the length ranges seen in real Google reviews.

1 — Homepage: “The words of our brides”

Hairline grid on a 6-track base so every row is always full: 3 = one row of thirds; 6 = 3 × 2; 5 = 3 + 2 (the two lower cards each take half the row, so there is no empty cell to paint); 4 and 2 = two columns; 1 = a single featured quote, unframed. Occasion is gone; the freed right-hand slot of the card footer now carries the reviewer’s real star rating. Long quotes are cut at 40 words on this section only.

Badge: no change (below).
