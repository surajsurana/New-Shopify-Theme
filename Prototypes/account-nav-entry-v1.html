1 — Desktop icon cluster: Search · Account · Wishlist · Bag

Placement decision: Account and Wishlist do NOT join the top-tier text links (Signature / Collections / Client Diaries). That row is deliberately short and exclusive — three curated doors into the collections, read as editorial choices, not a utility menu. Account and Wishlist are utility, not editorial, so they belong with Search and Bag in the icon cluster at the right — the same tier the brand already uses for "things you do," not "things you browse."

Order — Search / Account / Wishlist / Bag: reads left to right as a narrative — find something → who you are → what you've kept → what you're buying — and matches the icon order used by Net-a-Porter, Mytheresa and Moda Operandi, the closest luxury-fashion-ecommerce benchmarks for this exact 4-icon pattern. Four thin-line icons at this scale still reads as quiet and considered, not as a busier header.

Icon choice: a minimal person-outline for Account, a minimal heart-outline for Wishlist — both drawn to the identical spec already governing Search and Bag (24x24 viewBox, 1.4 stroke, round caps). No filled icons, no color at rest — color is reserved entirely for state (the rosegold "signed in" dot, the rosegold saved-count badge), so the icons themselves stay visually silent until they have something to say.

2 — Mobile: hamburger drawer, not the header row

Why the mobile header itself stays untouched: today's mobile action cluster (Search + Bag) already sits at its tested minimum width, hand-tuned once already to keep the logo perfectly centred (see ka-nav.css's own comments on this). Adding two more icons there would either shrink hit targets below a comfortable tap size or push the logo off-centre again. A luxury brand's mobile header should feel even calmer than desktop, not busier — so Account and Wishlist move to the drawer instead, styled as two new rows using the exact row treatment the "My Bag" row already established (Round 2 addition), not a new row style.

Row order — My Account, My Wishlist, My Bag: mirrors the desktop cluster's left-to-right order top-to-bottom, directly below the main link list. The Wishlist row shows its own count on the right in the same rosegold text style already used for the Bag row's count — no new badge component for mobile either.

This is the same drawer that opens from the hamburger already in production — only the two new rows are added, everything else (links, Currency, Concierge) is unchanged.
