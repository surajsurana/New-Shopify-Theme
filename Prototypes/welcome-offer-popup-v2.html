What changed from v1

Suraj reviewed the built-and-staged v1 version and asked for three specific changes, all reflected below. Everything else — the engagement trigger, the suppression/eligibility rules, the mutual-exclusion behaviour with search/drawer, the mobile bottom-sheet approach, and the overall restrained tone — carries over unchanged from v1.

  • 1. Email capture removed entirely. No "email this to yourself" field, no form, no tie-in to the footer's Inner Circle signup. The card is offer + code + CTA, nothing else.
  • 2. Amount and code are now the visual focus. "₹3,000" is now the largest, highest-contrast element in the card (charcoal, not the softer rosegold used in v1 — rosegold-on-paper tested too low-contrast to read as "unmistakable at a glance"). The code plate is enlarged and given a firmer rosegold border so it reads as the second clear anchor, immediately under the amount.
  • 3. Copy cut to the essentials. The long "every piece begins with a conversation…" paragraph is gone, replaced by one seven-word line. Fine print is now a single compact line instead of a full sentence with three clauses.

v1 is kept at Prototypes/welcome-offer-popup-v1.html for reference/history only — this file is the current, authoritative version.

On dropping the title line: v1 had a separate italic headline ("Consider This Our Welcome.") above the amount. Removed in v2 — with the amount now this large, a headline above it competed for the same "first thing you read" position instead of reinforcing it. The eyebrow alone ("A Welcome, From Us") still carries the "this is a gesture, not a sale" framing in three words.
Typography fix — the code plate's baseline (post-review): Suraj flagged "KLP" sitting visibly higher than "3000" in the code plate — a real bug, not a style note. Cause: the code was set in --f-display (Cormorant Garamond), whose digits are drawn as old-style figures — designed to blend with lowercase text, so they genuinely don't share a cap-height baseline with capital letters. Fixed by switching the code specifically to --f-sans (Jost) — already in this project's font stack, a geometric sans with uniform lining figures — plus an explicit font-variant-numeric: lining-nums tabular-nums as a defensive guarantee rather than relying on an unstated font default. Font-size trimmed 1.7rem → 1.5rem and letter-spacing 0.1em → 0.08em only to compensate for Jost's caps reading visually larger/bolder than the serif did at the same size — the code plate's prominence relative to the amount above it is otherwise unchanged. The oversized amount stays in --f-display; only the code switched.

D — Who sees it, and how often

Unchanged from v1 — none of the three requested changes touch trigger or suppression logic. Use the demo controls above (top of page) to flip your browser into each state and re-scroll the live section to confirm.

Shows

First-time visitor, genuinely engaged

No prior dismiss/claim on this device, not a returning signed-in customer, and has scrolled ~60% of the current page or spent ~25s on site. Shown once for the session.

Suppressed 30 days

Dismissed ("Not today" / × / tap-outside)

One graceful re-invitation is fine; nagging isn't. Resurfaces after 30 days of no further action.

Never again

Claimed (copied code, or clicked "Begin Shopping")

Permanent suppression on that device. (v1 also counted "sent by email" as a claim — removed along with the email field itself.)

Never eligible

Signed-in customer with an existing order

customer.orders_count > 0 — checked server-side in Liquid before any JS trigger logic runs.

Excluded pages

Cart page

A visitor already at the cart is transacting, not browsing.

Deferred, not shown

Search overlay / mobile drawer already open

Mutually exclusive with other overlays — waits and re-checks after they close, rather than stacking.
